# Missing device UI panels

Status: planning inventory, 2026-10-11. Each proposed `PANEL-*` is one swappable slot UI under [`PANEL-MODULE-CONTRACT`](../patterns/PANEL-MODULE-CONTRACT.md). The existing [title-left header](PANEL-HEADER-TITLE-LEFT.md) and [roster carousel body](PANEL-BODY-ROSTER-CAROUSEL.md) cover sign-in, not the remaining x02 stages.

Avoid assuming v1 ribbons remain. |

## Handoff checks

Give each panel a parent layout slot, chrome/content bounds, minimum and maximum content examples, state table, `UI-OPEN-###` items, and explicit readiness. The [LVGL assessment](../assessments/ASSESS-SHELL-x02.md) identifies full repaint and scroll-time rebuild as performance hazards; specify visual updates that can stay local to the panel.
