## Original trigger and causal change

Preserved baseline actual LVGL reversal checkpoint retains focus m8 while raw
viewport reaches index2. Old completion returns viewport to m8/x1070. A later
programmatic replacement has three starts but only two ends. These are the
original confirmed F003 triggers, not speculative adjacent risks.

Snap now owns one static explicit envelope with frozen monotonic ID, session,
applied revision, submission time, target, focus/message ID, callback and
presentation handles, plus RUNNING/TERMINAL status. Every acceptance emits a
fresh snap_start, including no-motion. Terminal status is set before callbacks
or deletion; exactly one snap_end uses that operation's immutable ID and input.
LVGL copies the ID in animation user_data. Both actual custom exec and completed
callbacks compare it before reading current handles or moving the viewport.
Archived completed/deleted callbacks cannot repeat terminals. Worker
lab02_snap_current_id remains atomic telemetry only.

Real SCROLL_BEGIN terminalizes the active snap as stale/reversed. Only BEGIN/END
synchronously generated by the custom tick's scroll_to are suppressed; SCROLL
still presents actual geometry continuously. The controller captures replacement
focus in the session before unlock may reconcile pending mutation. It relocks
motion and computes the new target from the reconciled owner focus/count, so
inserted/removed IDs cannot leave a stale target index. Immediate nonanimated
focus also supersedes old animation. Scroller DELETE invalidates its handle before
cancelling; session-generation change prevents old tick writes. External LVGL
animation deletion emits cancellation and unlocks owner reconciliation.

C3b's four roots/20 nodes, 320/132/12 geometry, every-displacement viewport coverage,
preserved overlapping bindings, one latest focus slot and 20ms coalescing survive.
No session/source ownership move, blocking wait, per-tick allocation, large page
stack copy, host/server/privateconfig/shared-Wi-Fi edit or F006 policy change.
One envelope/one LVGL animation and <=240-byte trace buffer are documented;
animation allocation failure has a cancelled terminal. Physical resource/timing
budgets remain OPEN.

## Terminal contract

Each ID receives one start and one snap_end:

- success: completed or no_motion;
- stale: reversed, superseded, scroller_deleted or session_changed;
- cancelled: animation_deleted or animation_allocation_failed.

snap_end includes frozen session/ID/revision/focus/message ID, outcome/reason,
before=running/after=terminal, elapsed_us and target_x. Start includes
before=pending/after=running and start/target/revision. Archived callbacks after
terminal are inert because the old operation already emitted its stale outcome.
Terminal operation-input traces precede owner reconciliation; page_apply/bind and
C0_STATE establish resulting owner focus and viewport. Existing parser event names
are retained for C5 schema work; IDs must be paired by identity, not event order.
