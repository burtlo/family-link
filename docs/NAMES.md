# Name ideas

The job is **keeping a connection going** — small photos, voice notes, and a live hangout — not a gadget brand and not a reminder of the split household.

Folder is still `family-link` until one of these sticks.

## Shortlist

| Name | Why it might work | Risk |
|---|---|---|
| **Hearth** | The thing that stays on in the house. Warm, not cute. | Slightly poetic; some people hear “fireplace product.” |
| **Porchlight** | Left on so you can find your way to each other. | Long. Two words. |
| **Beside** | Sits beside the Switch and beside their day. Quiet. | Easy to confuse in speech (“besides”). |
| **Thread** | One thread per child; later they join the same thread. | Generic in software (thread = stack). |
| **Sidecar** | Literally next to the dock. Honest about “beside the game.” | Sounds like a motorcycle or a browser. |
| **Ember** | Stays warm between hangouts. | Game / fantasy overtones. |
| **Wick** | Small persistent flame. Short, easy to say. | Obscure until explained. |
| **OpenLine** | The line stays open. Maps to 1:1 then group. | Telecom-generic. |
| **Postcard** | Photos + a short note, not a feed. | Undersells live hangout. |
| **SameRoom** | The feeling you want, not the geography. | Three syllables, a bit slogan-y. |

## Also considered

**Keep**, **Stay**, **Reach**, **Across**, **Direct**, **The Line**, **Glow**, **Lantern**, **Partyline** (nice for the later group call; dated), **KitchenTable**, **LittleLine**, **Handset**.

## Avoid

- **Marco / Polo / Relay / Bridge / Split / TwoHouses** — either the old app or the family situation as the brand.
- **Box / ESP / Ink / Deck** — hardware nicknames, not the product.
- **Beacon / Alert / Check-in** — sounds like monitoring, not connection.

## How to pick

Say it as a sentence: “I left you a note on ____.” If it sounds like a chore or a tracker, drop it. If it sounds like a place that is still theirs, keep it.
